01 / CONCEPT NOTES

四個容易搞混的角色

先把它們想成一間電玩工作室。角色分清楚後，ArtCraft 和網頁遊戲就不再神祕。

01程式語言

Rust

像是工程師使用的精密工具箱。

拿來撰寫程式本體。它重視速度與記憶體安全，適合編輯器、遊戲引擎和需要大量運算的工具。

放進整體流程

工程師先用 Rust 寫好程式，再把它編譯成桌面版，或轉成 WebAssembly 給瀏覽器執行。

02執行格式

WebAssembly

像是把機器零件裝進瀏覽器能讀的貨櫃。

它不是程式語言，而是瀏覽器可執行的低階格式。Rust、C 和 C++ 都能編譯成 WASM。

放進整體流程

瀏覽器下載 .wasm 檔後，在本機執行程式。大型編輯器因此不必把每個操作都送到伺服器。

03新式繪圖介面

WebGPU

像是通往顯示卡的高速專用道路。

網站可以把大量繪圖與計算工作交給 GPU。適合影像編輯、3D、特效和複雜視覺工具。

放進整體流程

WebAssembly 負責程式邏輯，WebGPU 負責把畫面高效率地算出來並顯示。

04廣泛支援的繪圖介面

WebGL

像是較早蓋成、車種支援更廣的道路。

也是讓網頁使用 GPU 的技術。年代較久、相容性較高，很多網站會在 WebGPU 不可用時退回 WebGL。

它和 WebGPU 的差別

兩者都能使用 GPU。WebGPU 較新，控制力和運算能力更完整；WebGL 較舊，但目前仍是可靠的備用方案。

Rust 原始碼→編譯成 WASM→瀏覽器執行→WebGPU / WebGL 畫畫面

03 / WHERE DATA LIVES

GitHub 可以當後端嗎？

可以存放公開檔案，也能提供網站，但它不是完整後端。用店面的比喻最容易記。

倉

GitHub Repository

有版本紀錄的倉庫

保存程式碼、圖片、公開設定與網站檔案。適合保管作品，不適合保存密碼或使用者私人資料。

店

GitHub Pages

把倉庫商品擺到公開店面

把 HTML、CSS、JavaScript、WASM 與合法遊戲檔送給訪客瀏覽器。不能在伺服器上執行 Python 或 PHP。

抽

localStorage

放在訪客電腦裡的小抽屜

可保存主題、最高分和簡單設定。清除瀏覽器資料就可能消失，也不會自動同步到其他裝置。

櫃

真正的後端

有管理員和門鎖的資料櫃

登入、資料庫、雲端存檔、留言與秘密 API 金鑰需要 Supabase、Firebase、Cloudflare 或自己的伺服器。

安全原則任何放進 GitHub Pages 的內容都應視為公開。密碼、私人資料與 API 金鑰不能寫進前端程式。
